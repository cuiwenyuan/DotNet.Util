## NPOI 许可问题修复（NuGet 升级收尾）
- **问题**：昨天把 NPOI 升到 2.8.0，构建 Plus 时出现 `NPOI: You must accept the OSMF EULA license` 警告（NPOI.targets 强制提示）。
- **核实**：NPOI 2.8.0 起许可从 Apache-2.0 改为 **OSMF EULA 商业许可**（nuspec `<license type="file">OSMFEULA.txt</license>`）；2.7.5/2.7.6 仍为 Apache-2.0 免费（`<license type="expression">Apache-2.0</license>`）。
- **修复**：DotNet.Util.Plus.csproj 三处 NPOI 2.8.0 → **2.7.6**（免费版最高，TFM 组与 2.7.5 一致：net472/ns2.0/ns2.1/net8.0；net9/10 消费 net8.0 资产；net46/47 仍保持 2.5.6——2.7.x 无 net46 资产）。注释标注"2.8.0 起为 OSMF EULA 商业许可"。
- **验证**：Plus net8.0/net10.0/ns2.0/net46 四 TFM 构建 0 错误且 OSMF/EULA 警告消失；Test net6.0 0 错误。
- 经验：升级 NuGet 前应检查 nuspec 的 `<license>` 节点，商业许可包（如 NPOI 2.8.0）不能直接引入开源库。
