## VS 2026 CS0579 根因与修复（已解决）
- 用户最终报错：`error CS0579: Duplicate 'global::System.Runtime.Versioning.TargetFrameworkAttribute' attribute`（多工程批量）。
- **根因**：前几轮多 TFM 验证时，我把**自定义输出目录 `verify_obj/` 建在了各工程目录下**（`DotNet.Util`/`Cache`/`Db`/`Plus`/`Tests` 共 5 个）。SDK 风格工程默认 glob `**/*.cs`（仅排除 obj/bin），于是 `verify_obj/Debug/net8.0/.NETCoreApp,Version=v8.0.AssemblyAttributes.cs` 与 `DotNet.Util.AssemblyInfo.cs` 这些**自动生成的** `.cs`（声明 `[assembly: TargetFrameworkAttribute(...)]`）被 VS 当成源码一起编译 → 与 SDK 生成的同一特性重复 → CS0579。这也是为何之前 `--no-restore -p:GenerateAssemblyInfo=false` 能过（SDK 不生成那份、无重复）、VS 正常编（GenerateAssemblyInfo=true）就炸。
- **修复**：删除这 5 个 `verify_obj/` 目录（纯生成产物、零源码）。删除后逐个正常模式编译验证：受影响 5 工程 + 其余（Business/Business.Web 全 TFM、Model/各 Db.*/Test/Web.UI.BasePage 抽样 TFM）均 0 错误、无 CS0579。
- **排除项**：源码唯一手写 `AssemblyInfo.cs` 在 `DotNet.Test.452`（旧格式非 SDK 工程，`packages.config`+`TargetFrameworkVersion`），不自动生成特性且不含 TargetFrameworkAttribute，不冲突，无需改动。
- **教训（重要）**：今后多 TFM 验证编译，**绝不要把自定义 OutputPath/IntermediateOutputPath 指向工程目录树下**（会被 `**/*.cs` glob 误编成源码 → CS0579）。应指向工程树之外（如 `/tmp/verify` 或仓库外的 gitignored 绝对路径）；或沿用既有 obj 资产用 `--no-restore`，并 `-p:GenerateAssemblyInfo=false -p:GenerateTargetFrameworkAttribute=false` 绕 IDE obj 锁——临时产物目录必须建在树外并及时清理。

## NPOI XWPFRun.SetUnderline CS0117 修复（已解决）
- 用户再报 VS 2026 编译错：`'XWPFRun' does not contain a definition for 'SetUnderline'`（CS0117）+ 警告 CS1591。
- **XWPFRun 根因**：`DotNet.Util.Plus/WordUtil.TemplateExport.cs:479-485` 用 `#if NET6_0_OR_GREATER` 区分 NPOI API，但漏了 **netstandard2.0/2.1**（它们也引用 NPOI 2.7.6，而 2.7.6 已移除 `SetUnderline`、`Underline` 改为可写属性）。`NET6_0_OR_GREATER` 在 netstandard 下未定义 → 误走 `SetUnderline` 分支 → CS0117。csproj 的 NPOI 映射：net48/net472 用 2.5.6（有 SetUnderline），其余（netstandard2.0/2.1 + net6~10）用 2.7.6。
- **修复**：条件改为 `#if NETFRAMEWORK`（net46/47/48 走 `SetUnderline`，非 Framework 走 `tarR.Underline = srcR.Underline`）。验证 `DotNet.Util.Plus` **全 10 个 TFM（net46→net10.0）0 错误**。
- **CS1591**：纯警告（13 个工程开 `GenerateDocumentationFile`、无 `TreatWarningsAsErrors`，不阻断编译；真正阻断是上面的 CS0117）。标准处理：新增 `src/Directory.Build.props` 统一 `<NoWarn>$(NoWarn);1591</NoWarn>`。验证 DotNet.Util net8.0 编译 CS1591 出现次数=0、error=0。
