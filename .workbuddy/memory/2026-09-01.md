## 新实证发现：CsvUtil 转义双引号残留缺陷（Bug 2 修复未尽）

`CsvUtil.ReadSpecialCharacter`（CsvUtil.cs:572）判断 `str.EndsWith("\"") && !str.EndsWith("\"\"")`，
当字段内容**以转义双引号结尾**时（如 CSV `"He said ""hi"""`），字符串末尾是 `"""`，`EndsWith("\"\"")` 为真 → 误入 else 分支 → 向后找不到结束项 → `txt` 保持 `""` → **字段被静默清空 + 列错位**。

验证：独立控制台 `C:\Temp\verify_csv`（复刻修复后方法体），结果
- `Tom,"hello,world",20` → PASS
- `Tom,"hello",20` → PASS
- `Tom,"He said ""hi""",20` → **FAIL，实际为空串**
- `Tom,"He said ""hi"""` → **FAIL，实际为空串**

根因：用「是否以 `""` 结尾」判断字段是否闭合不准确；且 `Trim('"')` 会过度裁剪首尾所有引号。彻底修法→改为**逐字符状态机**（按 RFC 4180：引号内遇到 `""` 视为字面引号并跳过，遇到单独 `"` 视为字段结束）。

```
dotnet test src/DotNet.Util.Tests/DotNet.Util.Tests.csproj -c Debug -f net8.0 \
  -p:GenerateAssemblyInfo=false -p:GenerateTargetFrameworkAttribute=false \
  --filter "FullyQualifiedName!~IntegrationTests"
```
